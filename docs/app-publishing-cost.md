# App 上架成本評估

2026-10-01 · 線上版：https://claude.ai/code/artifact/a36d8316-ade5-407d-818e-6bad7a6e3c62

**先上 Android；iOS 用 Codemagic 雲端打包或買 MacBook Air，都用 iPad Air 測試。**

## 兩平台比較

|  | Android（Google Play） | iOS（App Store） |
| --- | --- | --- |
| 帳號費用 | US$25 一次（約 NT$800） | US$99／年（約 NT$3,200） |
| 開發／打包 | 現有 Windows 電腦 | Codemagic 雲端或自備 Mac |
| 測試裝置 | 現有 Android 手機 | iPad Air（TestFlight） |
| 上架門檻 | 需 12 人 × 14 天封閉測試 | 送審約 1–3 天 |

## 要買 Mac 的話

| 機型 | 台灣售價（2026-06 調價後） | 評估 |
| --- | --- | --- |
| MacBook Air 13 吋 | NT$42,900 起 | 推薦：可攜，選 16GB 以上 |
| Mac mini（M4） | NT$26,900 起（二手約 1.2–1.8 萬） | 最省，但不能帶著走 |
| MacBook Neo | NT$22,900 起 | 規格偏入門，需確認記憶體 |
| MacBook Pro 14 吋 | NT$64,900 起 | 效能過剩 |
| Mac Pro | 約 NT$22 萬起 | 影音工作站，不需要 |

## 方案

| 方案 | 第一年 | 之後每年 |
| --- | --- | --- |
| A. Android + iOS（Codemagic 雲端打包） | 約 NT$4,000 | 約 NT$3,200 |
| B. Android + iOS（買 MacBook Air 13 吋） | 約 NT$47,000 | 約 NT$3,200 |
