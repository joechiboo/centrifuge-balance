# 全球化計畫（v1.1.0）

狀態：計畫中，尚未動工（2026-10-03）
目標版本：`1.1.0+2`

## 目標

v1.0.0 只上架台灣、只有繁體中文。下一版讓其他國家的玩家也能玩：

1. **先減字**：畫面已經能表達的，就不再用文字重複說明
2. **再翻譯**：剩下的文字改成多語系，第一個新增的語言是**英文**
3. **上架全球**：補英文商店資訊與截圖，Play 的國家／地區改成全部

## 第一階段：減字

原則：**圖像、顏色、動畫已經說清楚的，就不要再加一句話。** 減掉的字串越多，翻譯越少，畫面也越乾淨。

| 現在 | 改成 | 備註 |
|---|---|---|
| 「第 4 關・放 3 支」＋「1 支已固定，1 孔故障」 | 關卡編號＋試管圖示和數字（例如試管 `1/3`）；固定管、故障孔靠圖例的顏色表達 | 轉盤中間已經顯示 `1/3` |
| 「配平成功」＋「一次就過・點一下繼續」 | 打勾動畫＋「一次就過」用星星或圖示表示；「點一下繼續」改成畫面上的箭頭按鈕 | |
| 「重心偏向箭頭那一側」 | 拿掉，紅色箭頭本身就是答案 | 不平衡的震動和箭頭已經足夠 |
| 關卡文字提示（10 句，最長 50 多字） | **待決定**：按一次「提示」就直接畫虛線擺法，不先給文字；或保留文字但改短 | 虛線本身就是答案；拿掉文字會讓提示變簡單，要試玩後再決定 |
| 按鈕文字（提示、啟動、清空） | 保留圖示，文字可以留（短，好翻譯） | |

**保留並翻譯的：** 說明頁的「背後的數學」（這是賣點）、隱私權政策、圖例。

## 第二階段：多語系

- 用 Flutter 內建的 `gen-l10n`：新增 `l10n.yaml`、`lib/l10n/app_zh_TW.arb`（原文）、`app_en.arb`
- 依手機系統語言自動切換；系統語言不是中文時**預設顯示英文**
- 中文維持繁體；簡體中文暫不做（簡體系統的手機看到繁體還讀得懂）
- 數字、孔數、rpm 這類用 `intl` 的格式化，不要把數字拼進句子裡
- 關卡提示如果保留文字，也放進 ARB，key 用關卡編號（`hintLevel1`…）
- 隱私權政策頁的英文，直接用網頁版 `privacy.html` 的英文段落
